# Расчёт затвердевания опорного валка

Откройте **RollCasting.exe** в Windows x64. При запуске программа рассчитывает демонстрационный валок. Те же исходные данные сохранены в **demo.roll**. Размеры, температуры и свойства в этом проекте условные. Они позволяют проверить работу программы и не представляют паспорт стали 150ХНМ или режим реальной плавки.

## Работа с программой

1. В «Геометрии» задайте диаметры и высоты нижней шейки, бочки, верхней шейки и прибыли, толщины песка и опоки. Укажите название расчёта и источник данных.
2. В «Материалах» заполните постоянные свойства и параметры фазового перехода. Плотность расплава задаёт также расчётную массу ячеек. Плотность твёрдой фазы можно задать нулём, чтобы отключить оценку объёмов фаз и дефицита.
3. В «Условиях» задайте начальные температуры, коэффициенты боковой теплоотдачи, длительность, максимальный шаг и число ячеек по радиусу металла. Наружная теплоотдача 0 соответствует изоляции наружной поверхности.
4. Нажмите «Рассчитать». Таблица «Состояние всех отделений» показывает корку и объёмы каждого участка в выбранный момент. Ползунок управляет таблицей, разрезом и курсором графика. Стрелки перемещают на один сохранённый кадр, а Home и End переходят в начало и конец. Для демонстрационного проекта один кадр равен 30 секундам.
5. Выберите участок, чтобы посмотреть его кривые охлаждения и оценку момента полного затвердевания. График показывает температуры ближайших к оси и стенке ячеек и датчика на заданной глубине. Кнопка «Закрепить базу» добавляет кривую базового датчика после нового расчёта, если заданная глубина входит в оба участка.
6. «Сохранить» записывает параметры и версию модели в файл `.roll`. «Открыть» автоматически воспроизводит расчёт. «CSV» выгружает сохранённые кадры всех четырёх участков. Сохраняйте оба файла, если нужны исходные условия и таблица результатов. CSV имеет кодировку UTF-8 с BOM и разделитель «точка с запятой».

## Модель и интерпретация

Время отсчитывается от окончания заполнения формы. Валок состоит из четырёх цилиндрических участков. Каждый участок решается отдельно с осевой симметрией и теплоизолированными торцами. Сифон и питатель на разрезе показывают направление подвода и не входят в тепловую сетку. Толщины песка и опоки задаются отдельно для каждого участка.

Теплопроводность по радиусу рассчитывается методом конечных объёмов на кольцевых ячейках. Используются неявный шаг по времени, контактные сопротивления между материалами и конвективная отдача с наружной поверхности. Удельная энтальпия металла равна `c·T + L·(1 − fₛ)`, где `fₛ` — массовая доля твёрдой фазы. Она меняется линейно между ликвидусом и солидусом. Программа сохраняет до 10 001 кадра на участок. Если шагов больше, она прореживает вывод без укрупнения шага решателя. Время достижения солидуса оценивается по соседним внутренним шагам, а толщина корки — по полностью затвердевшим ячейкам, прилегающим к стенке.

**Объёмы зон** относятся к неподвижной геометрической сетке. Двухфазная зона включает ячейки, в которых одновременно присутствуют твёрдая и жидкая фазы. **Объёмы фаз** вычисляются из массы соответствующей фазы и заданной плотности. Дефицит объёма — разность между начальным геометрическим объёмом расплава и суммой объёмов фаз. Он отражает смену фаз при постоянных плотностях. Переток из прибыли, тепловое изменение плотностей, положение и форма усадочной раковины находятся за границами этой постановки.

Расчётное ядро на C++20 не зависит от интерфейса. Версия 1 использует нативный интерфейс Win32 и запускается без Qt. Для перехода к производственным данным нужны параметры целевой плавки, температурно-зависимые свойства и проверка по измерениям. Опубликованные кривые Вдовина и соавторов (2020) получены для другой формы и могут служить отдельным ориентиром после воспроизведения её условий.

## Сборка и проверка

Требуются CMake и компилятор с поддержкой C++20. Сборка интерфейса доступна под Windows. Ядро и проверки можно собирать отдельно на других платформах.

```powershell
cmake -S . -B build
cmake --build build --config Release
ctest --test-dir build -C Release --output-on-failure
```

Команда для MinGW без CMake из папки с исходниками

```powershell
g++ -std=c++20 -O2 -static -DUNICODE -D_UNICODE -municode -mwindows model.cpp project.cpp view.cpp main.cpp -lcomctl32 -lcomdlg32 -lgdi32 -o RollCasting.exe
g++ -std=c++20 -O2 -static model.cpp project.cpp checks.cpp -o casting_checks.exe
.\casting_checks.exe
```

Проверки охватывают сохранение энергии, баланс геометрических и фазовых объёмов, чувствительность к шагу и сетке, предел задачи Стефана для большого цилиндра и запись проекта и CSV. Это численная проверка реализации. Для оценки точности на производстве нужны экспериментальные кривые и сопоставимые условия заливки.
